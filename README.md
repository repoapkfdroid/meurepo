O Kawaks é um dos melhores emuladores de arcade, simples, leve, completo.

Você pode combinar os botões para ficar mais prático para fazer os combos

Além disso, você tem opção de personalizar a skin do seu gosto, mudando as imagens do botões, sendo assim jogando cada vez com uma skin diferente 

Você pode até criar sua própria skin e adicionar no emulador
